# Google Play — Content rating (IARC questionnaire draft)

Use **Play Console → App content → Content rating** → start questionnaire.

Suggested answers for KupaPay (`com.kupapay.mobile`):

| Question area | Answer |
|---------------|--------|
| Category | Utility / Productivity / Finance tool (not a game) |
| User-generated content shared publicly | **No** (group data is private to members) |
| Violence, sexual content, gambling, drugs | **No** |
| In-app purchases | **Yes** — subscriptions and one-time Trip Pass (KupaPay Pro) |
| Ads | **Yes** — optional rewarded video (AdMob) to unlock some actions; Pro removes ads |
| Location | **No** continuous location collection |
| Target audience | **18+** (financial / expense tool) |
| News app | **No** |
| Government app | **No** |

Expected result: low age rating (e.g. Everyone / 3+ / PEGI 3) depending on region; financial IAP and ads may add store labels only.

After questionnaire completes, download the certificate and attach to the Play listing before promoting beyond internal testing.
